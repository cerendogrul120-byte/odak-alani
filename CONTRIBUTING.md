# 🤝 OdakAlanı Katkıda Bulunma Rehberi

OdakAlanı projesine katkıda bulunmak istediğiniz için teşekkürler! Topluluk katkıları projeyi herkes için daha iyi hale getirir.

## 🚀 Nasıl Katkı Sağlayabilirsiniz?

1. **Hata Bildirimi:** Karşılaştığınız bir problem varsa GitHub Issues sekmesinden `Hata Bildirimi` şablonunu kullanarak bildirebilirsiniz.
2. **Yeni Fikirler:** Yeni bir ortam sesi, arayüz teması veya verimlilik aracı önerisi için `Özellik Önerisi` açabilirsiniz.
3. **Kod Katkısı:**
   - Projeyi forklayın.
   - Yeni bir özellik dalı (branch) oluşturun: `git checkout -b ozellik/yeni-tema`
   - Kod değişikliklerinizi yapın ve test edin.
   - Anlaşılır commit mesajları ile kaydedin: `git commit -m "feat: Gece yarısı teması eklendi"`
   - Dalınızı itin ve bir **Pull Request** açın.

## 📌 Kod Kuralları
- Arayüz metinlerinin ve yorum satırlarının Türkçe olmasına özen gösterin.
- Harici ağır kütüphaneler yerine saf JavaScript (Vanilla JS), modern CSS ve Web Ses API kullanımını tercih edin.
